## 6. 观察项（不影响判定，交施工/运维会话知悉）

1. **`auto` 旗标的保守偏差**：规格 §3 W-1 对 gov_exercise_workflow.json 的括号注记为"auto 性质同 fingerprint"（fingerprint 为 auto=true）；实作为 `auto=false, enabled=false` 并在 rules 中明示"一键 runner 流程默认不执行（runner 行为零变化）"。这是在规格内部张力（C2 要求 runner 零变化 vs auto=true 会改变 runner 行为）之间取了保守解，且满足验收 C2 与"只影响新 engagement"的 P0 前提。仅记录，不构成 FAIL；WZ 会话经游标走该阶段不受影响。
2. **PATH `python` 无 pytest**：`python -m pytest` 与 `python scripts/verify_offline.py` 在 PATH 3.14.4 下不可用（脚本会明确报错并提示改用 `.venv`）。`.venv`（项目运行时矩阵中的"新工具默认"）下全绿。建议运维会话统一入口或更新文档口径。
3. **ROE Tier A 生效签字**：Tier A 段标题已注日期（2026-09-07 增补），正文生效条件为"操作者签字（ROE 变更记录注日期）"；ROE.md 目前无独立变更记录节。段内已带日期，实质满足"注日期"；操作者签字确认属操作步骤，建议在下一个真实 engagement 使用 Tier A 前完成一次显式签字动作。
4. **app_* 条目引用路径缺失**：`tool_strategy.json` 中 app_* 条目 notes 引用 `skills/app/references/package-analysis.md`，盘上不存在（`doc_drift` 未覆盖该引用形态）。属并行工作线的在途内容，不在本次验收范围内，仅如实记录。
